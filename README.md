# 🍳 Recipe Finder App

A web application built with React and Vite for the Free API Niche Challenge (Food & Recipes category).

## 🌟 Features
- Search recipes dynamically by dish name using **TheMealDB** REST API.
- Displays meal names, cuisine origin, category tags, images, and recipe summary descriptions.
- Responsive grid layout.

## 🔑 API & Environment Variables
- **API Provider:** [TheMealDB](https://www.themealdb.com/)
- **Configuration:** The API base URL is stored in an environment variable named `VITE_API_BASE_URL`.
- The `.env` file is included in `.gitignore` to ensure configuration keys are not committed directly to the repository.
